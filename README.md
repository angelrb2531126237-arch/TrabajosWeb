## Descripción

Este repositorio fue creado para almacenar las prácticas realizadas durante la materia de **Aplicaciones Web** de la Universidad Politécnica de Pachuca.

El propósito del repositorio es aplicar y comprobar el funcionamiento de las principales herramientas utilizadas durante el desarrollo de aplicaciones web, incluyendo:

* Visual Studio Code
* HTML
* CSS
* JavaScript
* Git
* GitHub
* Node.js
* npm
* Live Server
* Herramientas de desarrollo del navegador

## Práctica 1 - Configuración del entorno de desarrollo web

La carpeta `practica-01-entorno` contiene una página web desarrollada con HTML, CSS y JavaScript que permite verificar que el entorno de desarrollo se encuentra instalado y configurado correctamente.

### Archivos

`index.html` - estructura de la página web.

`style.css` - estilos de la página.

`script.js` - funcionalidad e interacción mediante JavaScript.
